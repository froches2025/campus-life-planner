# Campus Life Planner

A web app for managing tasks, built with vanilla JavaScript, HTML, and CSS.

## Implementation Notes

**Adapted from Assignment Starter Snippets:**
- `search.js`: The `compileRegex()` and `highlight()` functions are adapted from the assignment's official starter snippets. These implement standard regex compilation and text highlighting patterns.

## Features

- Form validation with regex patterns
- Task management (add, update, delete, search)
- Responsive design (mobile cards, desktop table)
- Advanced search with pattern support (e.g., `@tag:Health`)
- Accessibility features (ARIA labels, keyboard navigation)
